## 1. 传感器使用说明

### 1.1 算法背景

健身动作识别依赖手腕佩戴设备的运动传感器。通过分析手腕在运动过程中的加速度变化和角速度变化，可以识别出周期性的健身动作（如卧推、弯举等）。

### 1.2 使用的传感器

| 传感器类型 | 用途 | 数据维度 | 单位 |
|-----------|------|---------|------|
| 加速度计 (Accelerometer) | 检测线性加速度变化 | X, Y, Z 三轴 | m/s² |
| 陀螺仪 (Gyroscope) | 检测角速度变化 | X, Y, Z 三轴 | °/s (度/秒) |

### 1.3 坐标系定义

```
Apple Watch 坐标系（表盘朝上时）:
     +Y (向指尖方向)
      ↑
      │
      │
      ●───→ +X (向右侧方向)
     /
    ↙
   +Z (向表盘外/天空方向)
```

### 1.4 采样频率

```
SENSOR_INTERVAL = "ui"  // 对应约 60ms/次

计算采样率:
  采样频率 f = 1000ms / 60ms ≈ 16.67 Hz
  
Apple Watch 建议:
  CoreMotion 默认采样率: 50-100 Hz
  推荐使用: 50 Hz (每20ms采样一次)
```

### 1.5 传感器数据结构

```pseudocode
// 输入：单次传感器采样数据
STRUCT SensorReading:
    x: Float           // X轴数值
    y: Float           // Y轴数值  
    z: Float           // Z轴数值
    timestamp: Integer // 采样时间戳（毫秒）
END STRUCT

// 融合后的传感器数据
STRUCT FusedSensorData:
    raw: {
        acc: SensorReading,    // 原始加速度
        gyro: SensorReading    // 原始陀螺仪
    }
    filtered: {
        acc: SensorReading,    // 滤波后加速度

    }
    features: {
        accMagnitude: Float,   // 加速度向量模长
        gyroMagnitude: Float   // 陀螺仪向量模长
    }
    timestamp: Integer
END STRUCT
```

## 2. 数据滤波算法

### 2.1 算法背景

原始传感器数据包含高频噪声（设备振动、肌肉颤抖等），需要通过滤波平滑数据以提取有意义的运动特征。

### 2.2 滑动窗口均值滤波

#### 输入输出定义

```pseudocode
/**
 * 滑动窗口均值滤波
 * 
 * @input  dataBuffer: Array<SensorReading>  // 传感器数据缓冲区
 * @input  windowSize: Integer               // 滑动窗口大小
 * @output FilteredReading                   // 滤波后的数据点
 * 
 * 约束条件:
 *   - windowSize >= 1
 *   - dataBuffer.length >= 1
 */
```

#### 算法伪代码

```pseudocode
FUNCTION applyMovingAverageFilter(dataBuffer, windowSize):
    // 边界条件处理
    IF dataBuffer.length == 0 THEN
        RETURN { x: 0, y: 0, z: 0 }
    END IF
    
    // 实际窗口大小取较小值
    actualWindowSize = MIN(windowSize, dataBuffer.length)
    
    // 取最近 N 个数据点
    window = dataBuffer.slice(-actualWindowSize)
    
    // 计算各轴均值
    sumX = 0, sumY = 0, sumZ = 0
    FOR EACH reading IN window:
        sumX += reading.x
        sumY += reading.y
        sumZ += reading.z
    END FOR
    
    RETURN {
        x: sumX / actualWindowSize,
        y: sumY / actualWindowSize,
        z: sumZ / actualWindowSize
    }
END FUNCTION
```

#### 数学证明

设滑动窗口内的 n 个采样值为 $x_1, x_2, ..., x_n$，滤波输出为：

$$\bar{x} = \frac{1}{n}\sum_{i=1}^{n}x_i$$

**降噪效果证明：**

假设真实信号为 $s$，噪声为 $\epsilon_i$（独立同分布，均值为 0，方差为 $\sigma^2$），则：

$$x_i = s + \epsilon_i$$

滤波后：

$$\bar{x} = \frac{1}{n}\sum_{i=1}^{n}(s + \epsilon_i) = s + \frac{1}{n}\sum_{i=1}^{n}\epsilon_i$$

噪声部分的方差：

$$Var\left(\frac{1}{n}\sum_{i=1}^{n}\epsilon_i\right) = \frac{\sigma^2}{n}$$

**结论：** 滤波后噪声方差降低为原来的 $1/n$，窗口越大降噪效果越好，但会增加信号延迟。

#### 配置参数

```pseudocode
CONST WINDOW_SIZE = 5           // 滤波窗口大小
CONST SENSOR_BUFFER_SIZE = 100  // 传感器数据缓冲区大小
```

### 2.3 向量模长计算

```pseudocode
/**
 * 计算三维向量的欧几里得模长
 * 
 * @input  x, y, z: Float  // 三轴分量
 * @output Float           // 向量模长
 */
FUNCTION calculateMagnitude(x, y, z):
    RETURN SQRT(x² + y² + z²)
END FUNCTION

// 数学定义: ||v|| = √(x² + y² + z²)
```

## 3. 动作识别算法

### 3.1 算法背景

健身动作（如卧推）具有周期性特征：
1. **起始阶段**：从静止状态开始加速
2. **峰值阶段**：达到运动速度/加速度的极值
3. **回落阶段**：减速并回归静止

通过检测这个周期性模式，可以识别并计数单次动作。

### 3.2 状态机设计

```pseudocode
// 动作识别状态枚举
ENUM RecognitionState:
    IDLE            // 静止状态，等待运动开始
    MOTION_START    // 运动启动，检测到初始加速
    IN_PROGRESS     // 动作进行中，持续监测峰值
    PEAK_DETECTED   // 峰值检测成功，等待回落
    RETURNING       // 回归基线，准备确认动作完成
END ENUM
```

### 3.3 动作配置参数

```pseudocode
// 每种动作的识别参数配置
STRUCT RecognitionParams:
    primaryAxis: String      // 主监测轴 ("x", "y", "z", "xy_combined", "gyro_x", "gyro_y", "gyro_z")
    secondaryAxis: String    // 辅助监测轴（可为 null）
    peakThreshold: Float     // 峰值阈值 (m/s² 或 °/s)
    gyroThreshold: Float     // 陀螺仪阈值 (°/s)
    timeWindow: {
        min: Float,          // 最小动作时长（秒）
        max: Float           // 最大动作时长（秒）
    }
    baselineRange: Float     // 基线范围
END STRUCT

// 示例：杠铃卧推参数
BENCH_PRESS_PARAMS = {
    primaryAxis: "z",           // Z轴加速度为主
    secondaryAxis: "gyro_y",    // Y轴陀螺仪辅助验证
    peakThreshold: 1.5,         // 1.5 m/s²
    gyroThreshold: 30,          // 30 °/s
    timeWindow: { min: 0.8, max: 2.5 },
    baselineRange: 0.5
}
```

### 3.4 阈值系数常量

```pseudocode
// 各状态转换的阈值系数
CONST THRESHOLD_RATIOS = {
    MOTION_START: 0.5,      // 启动阈值 = peakThreshold × 0.5
    MOTION_CONTINUE: 0.7,   // 持续阈值 = peakThreshold × 0.7
    PEAK_DETECTED: 0.6,     // 峰值回落系数 = peakValue × 0.6
    RETURNING: 0.5          // 回归阈值 = peakThreshold × 0.5
}
```

### 3.5 核心识别算法

#### 输入输出定义

```pseudocode
/**
 * 动作识别器
 * 
 * @input  fusedData: FusedSensorData  // 融合后的传感器数据
 * @input  params: RecognitionParams   // 当前动作的识别参数
 * @output ActionEvent | null          // 检测到动作时触发事件
 * 
 * 状态维护:
 *   - currentState: RecognitionState  // 当前状态
 *   - peakValue: Float                // 记录的峰值
 *   - peakTime: Integer               // 峰值时间戳
 *   - motionStartTime: Integer        // 运动开始时间戳
 *   - dataBuffer: Array               // 数据缓冲区
 */
```

#### 主值提取算法

```pseudocode
FUNCTION extractPrimaryValue(fusedData, params):
    axis = params.primaryAxis
    acc = fusedData.filtered.acc
    gyro = fusedData.filtered.gyro
    
    SWITCH axis:
        CASE "x":
            RETURN ABS(acc.x)
        CASE "y":
            RETURN ABS(acc.y)
        CASE "z":
            RETURN ABS(acc.z)
        CASE "xy_combined":
            // X-Y平面组合向量模长
            RETURN SQRT(acc.x² + acc.y²)
        CASE "gyro_x":
            RETURN ABS(gyro.x)
        CASE "gyro_y":
            RETURN ABS(gyro.y)
        CASE "gyro_z":
            RETURN ABS(gyro.z)
        DEFAULT:
            RETURN fusedData.features.accMagnitude
    END SWITCH
END FUNCTION
```

#### 状态机处理算法

```pseudocode
FUNCTION processRecognition(fusedData):
    // 1. 添加到缓冲区并限制大小
    dataBuffer.push(fusedData)
    IF dataBuffer.length > RECOGNITION_BUFFER_SIZE THEN
        dataBuffer.shift()
    END IF
    
    // 2. 提取主监测值和辅助监测值
    value = extractPrimaryValue(fusedData, params)
    secondaryValue = extractSecondaryValue(fusedData, params)
    timestamp = fusedData.timestamp
    
    // 3. 状态机处理
    SWITCH currentState:
        CASE IDLE:
            handleIdleState(value, secondaryValue, timestamp)
        CASE MOTION_START:
            handleMotionStartState(value, secondaryValue, timestamp)
        CASE IN_PROGRESS:
            handleInProgressState(value, secondaryValue, timestamp)
        CASE PEAK_DETECTED:
            handlePeakDetectedState(value, secondaryValue, timestamp)
        CASE RETURNING:
            handleReturningState(value, secondaryValue, timestamp)
    END SWITCH
END FUNCTION
```

#### 各状态处理逻辑

```pseudocode
// ========== 静止状态处理 ==========
FUNCTION handleIdleState(value, secondaryValue, timestamp):
    // 检测是否超过启动阈值
    startThreshold = params.peakThreshold × THRESHOLD_RATIOS.MOTION_START
    
    IF value > startThreshold THEN
        currentState = MOTION_START
        motionStartTime = timestamp
        baselineValue = value
        LOG("动作启动检测")
    END IF
END FUNCTION

// ========== 运动启动状态处理 ==========
FUNCTION handleMotionStartState(value, secondaryValue, timestamp):
    continueThreshold = params.peakThreshold × THRESHOLD_RATIOS.MOTION_CONTINUE
    
    IF value > continueThreshold THEN
        // 确认运动持续，进入动作进行中
        currentState = IN_PROGRESS
        LOG("动作进行中")
    ELSE
        // 超时检测：运动未持续则返回静止
        elapsed = (timestamp - motionStartTime) / 1000
        IF elapsed > params.timeWindow.max THEN
            currentState = IDLE
            LOG("运动启动超时，返回静止")
        END IF
    END IF
END FUNCTION

// ========== 动作进行中状态处理 ==========
FUNCTION handleInProgressState(value, secondaryValue, timestamp):
    // 持续追踪峰值
    IF value > peakValue THEN
        peakValue = value
        peakTime = timestamp
    END IF
    
    // 检测是否达到峰值阈值
    IF peakValue >= params.peakThreshold THEN
        // 辅助轴验证（如果配置了辅助轴）
        secondaryCheck = TRUE
        IF params.secondaryAxis != null THEN
            secondaryCheck = (secondaryValue >= params.gyroThreshold)
        END IF
        
        IF secondaryCheck THEN
            currentState = PEAK_DETECTED
            LOG("峰值检测成功: " + peakValue)
        END IF
    END IF
    
    // 超时保护
    elapsed = (timestamp - motionStartTime) / 1000
    IF elapsed > params.timeWindow.max THEN
        currentState = IDLE
        peakValue = 0
        LOG("动作进行超时，返回静止")
    END IF
END FUNCTION

// ========== 峰值检测状态处理 ==========
FUNCTION handlePeakDetectedState(value, secondaryValue, timestamp):
    // 检测数值是否开始回落
    fallThreshold = peakValue × THRESHOLD_RATIOS.PEAK_DETECTED
    
    IF value < fallThreshold THEN
        currentState = RETURNING
        LOG("数值开始回落")
    END IF
END FUNCTION

// ========== 回归基线状态处理 ==========
FUNCTION handleReturningState(value, secondaryValue, timestamp):
    // 检测是否回归到基线附近
    baselineThreshold = params.peakThreshold × THRESHOLD_RATIOS.RETURNING
    
    IF value < baselineThreshold THEN
        // 时间窗口验证
        duration = (timestamp - motionStartTime) / 1000
        
        IF duration >= params.timeWindow.min AND duration <= params.timeWindow.max THEN
            // ✅ 动作完成！触发计数
            onActionComplete(duration, peakValue)
        ELSE
            LOG("时间窗口验证失败: " + duration)
        END IF
        
        // 重置状态
        currentState = IDLE
        peakValue = 0
        motionStartTime = 0
    END IF
END FUNCTION
```

#### 动作完成回调

```pseudocode
FUNCTION onActionComplete(duration, peakValue):
    LOG("动作完成! 耗时: " + duration + "秒")
    
    // 触发回调，通知上层
    IF onCountCallback != null THEN
        onCountCallback({
            duration: duration,
            peakValue: peakValue,
            timestamp: NOW()
        })
    END IF
END FUNCTION
```

## 4. 无效数据判定

### 4.1 算法背景

传感器可能产生异常数据（硬件故障、极端干扰、数值溢出等），需要在处理前过滤掉这些无效数据。

### 4.2 验证范围定义

```pseudocode
CONST VALIDATION_RANGE = {
    ACCELEROMETER_MAX: 200,    // 加速度最大值 ±200 m/s² (约±20g)
    GYROSCOPE_MAX: 2000        // 陀螺仪最大值 ±2000 °/s
}
```

### 4.3 加速度计数据验证

```pseudocode
/**
 * 验证加速度计数据有效性
 * 
 * @input  data: SensorReading  // 原始加速度数据
 * @output Boolean              // true=有效, false=无效
 * 
 * 边界条件:
 *   1. 数据对象不能为 null
 *   2. x, y, z 必须是有效数字（非 NaN）
 *   3. 各轴绝对值不超过最大范围
 */
FUNCTION validateAccelerometerData(data):
    // 检查数据对象存在性
    IF data == null OR typeof(data) != "object" THEN
        RETURN FALSE
    END IF
    
    x = data.x
    y = data.y
    z = data.z
    
    // 检查是否为有效数字
    IF isNaN(x) OR isNaN(y) OR isNaN(z) THEN
        RETURN FALSE
    END IF
    
    // 范围检查
    maxAcc = VALIDATION_RANGE.ACCELEROMETER_MAX
    IF ABS(x) > maxAcc OR ABS(y) > maxAcc OR ABS(z) > maxAcc THEN
        RETURN FALSE
    END IF
    
    RETURN TRUE
END FUNCTION
```

### 4.4 陀螺仪数据验证

```pseudocode
/**
 * 验证陀螺仪数据有效性
 * 
 * @input  data: SensorReading  // 原始陀螺仪数据
 * @output Boolean              // true=有效, false=无效
 */
FUNCTION validateGyroscopeData(data):
    // 检查数据对象存在性
    IF data == null OR typeof(data) != "object" THEN
        RETURN FALSE
    END IF
    
    x = data.x
    y = data.y
    z = data.z
    
    // 检查是否为有效数字
    IF isNaN(x) OR isNaN(y) OR isNaN(z) THEN
        RETURN FALSE
    END IF
    
    // 范围检查
    maxGyro = VALIDATION_RANGE.GYROSCOPE_MAX
    IF ABS(x) > maxGyro OR ABS(y) > maxGyro OR ABS(z) > maxGyro THEN
        RETURN FALSE
    END IF
    
    RETURN TRUE
END FUNCTION
```

### 4.5 无效数据处理策略

```pseudocode
FUNCTION onSensorData(rawData):
    // 验证数据有效性
    IF NOT validateData(rawData) THEN
        // 丢弃无效数据，不加入缓冲区

    END IF
    
    // 有效数据继续处理

    processFusedData()
END FUNCTION
```

### 5.3 记录ID生成算法

```pseudocode
/**
 * 生成唯一训练记录ID
 * 
 * @output String  // 格式: rec_YYYYMMDD_XXX
 * 
 * 设计说明:
 *   - 日期前缀便于按日期分组查询
 *   - 3位随机数避免同日冲突
 */
FUNCTION generateRecordId():
    now = getCurrentDateTime()
    
    dateStr = now.year + 
              padZero(now.month, 2) + 
              padZero(now.day, 2)
    
    randomStr = padZero(RANDOM(0, 999), 3)
    
    RETURN "rec_" + dateStr + "_" + randomStr
END FUNCTION

// 辅助函数：左侧补零
FUNCTION padZero(num, length):
    RETURN STRING(num).padStart(length, '0')
END FUNCTION
```

### 5.4 核心存储操作

```pseudocode
// ========== 保存训练记录 ==========
ASYNC FUNCTION saveRecord(record):
    TRY
        // 获取现有记录
        records = AWAIT getAllRecords()
        
        // 生成ID和时间戳
        IF record.recordId == null THEN
            record.recordId = generateRecordId()
        END IF
        IF record.timestamp == null THEN
            record.timestamp = NOW()
        END IF
        IF record.date == null THEN
            record.date = formatDate(record.timestamp)
        END IF
        
        // 追加新记录
        records.push(record)
        
        // 持久化存储
        AWAIT storage.set(
            key: STORAGE_KEYS.TRAINING_RECORDS,
            value: JSON.stringify(records)
        )
        
        RETURN TRUE
    CATCH error
        LOG("保存失败: " + error)
        RETURN FALSE
    END TRY
END FUNCTION

// ========== 获取所有记录 ==========
ASYNC FUNCTION getAllRecords():
    TRY
        data = AWAIT storage.get(
            key: STORAGE_KEYS.TRAINING_RECORDS,
            default: "[]"
        )
        records = JSON.parse(data)
        RETURN isArray(records) ? records : []
    CATCH
        RETURN []
    END TRY
END FUNCTION

// ========== 按日期查询 ==========
ASYNC FUNCTION getRecordsByDate(dateString):
    records = AWAIT getAllRecords()
    RETURN records.filter(r => r.date == dateString)
END FUNCTION

// ========== 按动作类型查询 ==========
ASYNC FUNCTION getRecordsByAction(actionCode):
    records = AWAIT getAllRecords()
    RETURN records.filter(r => r.actionCode == actionCode)
END FUNCTION

// ========== 获取最近N条记录 ==========
ASYNC FUNCTION getRecentRecords(count):
    records = AWAIT getAllRecords()
    sorted = records.sort((a, b) => b.timestamp - a.timestamp)
    RETURN sorted.slice(0, count)
END FUNCTION

// ========== 删除记录 ==========
ASYNC FUNCTION deleteRecord(recordId):
    TRY
        records = AWAIT getAllRecords()
        filtered = records.filter(r => r.recordId != recordId)
        AWAIT storage.set(
            key: STORAGE_KEYS.TRAINING_RECORDS,
            value: JSON.stringify(filtered)
        )
        RETURN TRUE
    CATCH
        RETURN FALSE
    END TRY
END FUNCTION
```
