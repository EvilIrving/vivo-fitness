## 1. 适用范围与实现约定

- **目标客户端**：仅 Apple Watch；UI 以 **SwiftUI** 表达，导航以 **`NavigationStack`（watchOS 9+）** 为主。
- **单位**：布局与字号在代码中使用 **点（pt）**；与设备物理像素关系由系统缩放，文档不采用 Web 的 `px` 或 Tailwind 式 token。
- **图标**：优先 **SF Symbols**（`Image(systemName:)`），避免依赖外链 SVG。
- **无障碍**：关键数字与状态应兼容 **动态字体**；若某屏必须固定大字展示，需单独评估可读性并尽量仍使用 `Font` 体系而非硬编码裸值。
- **历史原型**：旧版非 Watch 原型仅作存档，**不作为**实现约束。

## 2. 设计规范（Token）

### 2.1 屏幕与布局基准

- **尺寸**：以系统提供的 **布局边距与安全区** 为准；勿写死「手机宽度」类约束。
- **触控**：主要操作控件建议 **最小触控约 44×44 pt**（系统 HIG 建议）；表冠辅助可减小纯点按区域但仍需避免误触。
- **方向**：第一版假设 **单侧手腕、表冠朝向一致**（与 `docs/03` 一致）；需在校准/准备页用短文案提示。

### 2.2 颜色（建议放入 Asset Catalog）

语义化命名，浅色模式示例如下（深色模式可为同一语义提供另一套，由 Asset 管理）：

| 语义 token（示例名） | 用途 | 示例值 |
|---------------------|------|--------|
| `Brand.primary` | 主按钮、强调计数 | `#405EFF` |
| `Semantic.success` | 组完成、达标 | `#10B981` |
| `Semantic.warning` | 暂停 | `#F59E0B` |
| `Semantic.error` | 错误 | `#EF4444` |
| `Text.primary` | 主文案 | `#1F2937` |
| `Text.secondary` | 次要说明 | `#4B5563` |
| `Text.tertiary` | 辅助 | `#6B7280` |
| `Fill.subtle` | 次级按钮底 | `#F3F4F6` |
| `Separator.default` | 分隔 | `#D1D5DB` |

在 SwiftUI 中：`Color("Brand.primary")` 等，**避免**在多处散落裸十六进制。

### 2.3 字体层级（SwiftUI）

优先使用 **文本样式**；需要「超大数字」时再用 **标题样式放大** 或 **受限的** `.system(size:weight:design:)`。

| 用途 | 推荐 API | 说明 |
|------|-----------|------|
| 页面标题 | `.font(.headline)` 或 `.font(.title3)` | 依屏内层级二选一，全应用统一 |
| 动作名 / 组信息 | `.font(.subheadline)` + `.foregroundStyle(.secondary)` | 信息密度高时偏小号 |
| 正文说明 | `.font(.body)` | 校准步骤、错误提示 |
| 元数据（时间、组数） | `.font(.caption)` / `.font(.caption2)` | 列表次要信息 |
| 当前次数（训练中） | `.font(.title).bold()` 或 `.font(.system(size: 34, weight: .bold, design: .rounded))` | 需保证一眼可读 |
| 倒计时 / 完成大数字 | `.font(.system(size: 56, weight: .bold, design: .rounded))` 等 | **仅**用于少数屏；需在不同表盘尺寸上实测 |

**不要**再使用 `text-9xl` 等 Web 命名；若设计评审需要「档位表」，以上表格即为唯一来源。

### 2.4 间距与圆角

建议用 **私有枚举或常量** 统一间距（示例）：

```swift
enum Spacing {
    static let xs: CGFloat = 4
    static let sm: CGFloat = 8
    static let md: CGFloat = 12
    static let lg: CGFloat = 16
}
```

圆角：列表行、卡片可用 `8`～`12` pt；圆形按钮使用 `Circle()` 裁剪即可。

## 3. 信息架构与导航（SwiftUI）

### 3.1 视图树（逻辑页面）

以下名称与实现中的 `struct …View` 建议保持一致：

```
ActionListView                    // 入口：动作列表 + 历史入口
├── RepsSettingView               // 目标次数
│   ├── CalibrationView           // 无有效模板时：个人模板采样
│   └── TrainingReadyView         // 有模板时可直接进入；校准成功后进入
│           └── TrainingActiveView
│                   └── SetCompleteView
│                           ├── (继续) → TrainingActiveView   // 下一组
│                           └── (结束) → 回到 ActionListView 根（并保存）
└── TrainingHistoryView
        └── TrainingDetailView
```

**产品规则**：若某动作已有有效模板且未触发重校策略，可从 `RepsSettingView` **跳过** `CalibrationView` 进入 `TrainingReadyView`（与 `docs/03` 一致）。

### 3.2 「路由」在 SwiftUI 中的对应物

| 文档中的操作 | SwiftUI 实现思路 |
|-------------|------------------|
| push | `NavigationLink` / `navigationDestination` 入栈 |
| replace 当前页 | 替换 `NavigationPath` 的最后一个元素，或使用 `@State` 切换「子流程根视图」 |
| 返回 | `dismiss()` / `path.removeLast()` |
| 结束训练并回首页 | 将路径清空为根：`path = NavigationPath()` 或 `path.removeLast(path.count)` |

示例（简化，`repetitionEngine` 由上层通过工厂或 `EnvironmentObject` 注入）：

```swift
NavigationStack(path: $path) {
    ActionListView()
        .navigationDestination(for: Route.self) { route in
            switch route {
            case .reps(let action): RepsSettingView(action: action)
            case .calibration(let ctx): CalibrationView(context: ctx)
            case .ready(let ctx): TrainingReadyView(context: ctx)
            case .active(let ctx):
                TrainingActiveView(context: ctx, engine: repetitionEngine)
            case .complete(let summary):
                SetCompleteView(summary: summary, onContinue: { _ in }, onFinish: { })
            case .history: TrainingHistoryView()
            case .detail(let id): TrainingDetailView(recordID: id)
            }
        }
}
```

### 3.3 路由枚举（示例）

工程里可用 `Hashable` 枚举驱动 `navigationDestination`（字段可按数据模型增减）：

```swift
enum Route: Hashable {
    case reps(ActionRef)
    case calibration(TrainingContext)
    case ready(TrainingContext)
    case active(TrainingContext)           // 进入训练页时携带本组上下文
    case complete(SetSummary)             // 组完成摘要，见工程模型
    case history
    case detail(UUID)
}
```

### 3.4 训练子流程的状态载体

建议用 **值类型上下文**（`struct`）在视图间传递，避免散落裸参数：

```swift
struct ActionRef: Hashable {
    let code: String
    let name: String
}

struct TrainingContext: Hashable {
    let action: ActionRef
    var targetReps: Int
    var currentSet: Int
    // 校准成功后注入模板：若 MotionTemplate 不便 Hashable，可仅传递 templateID: UUID
    // var templateID: UUID?
}
```

## 4. 算法要点与 UI / 会话衔接

> 完整数学与状态机定义见 `docs/01`；此处只写 **与界面、会话生命周期相关** 的接口级说明，便于 UI 与引擎对齐。

### 4.1 双区间闭环（展示层理解）

- 一次有效重复 ≈ 在个体模板的 **A 区与 B 区** 之间完成可判定往返（细节见 `docs/01` 第 4 节）。
- **UI 责任**：在 `TrainingActiveView` 显示当前次数、目标、暂停状态；在计数增加时触发短触感；达标时触发成功触感并导航至 `SetCompleteView`。

### 4.2 传感器生命周期（与页面绑定）

| 阶段 | 采样 | 说明 |
|------|------|------|
| `CalibrationView` | 开 | 按 `docs/01` 完成静止段 + 连续样本；失败不进入正式计数 |
| `TrainingReadyView` | 通常关 | 倒计时仅 UI；若产品要求预热可在倒计时末段再开 |
| `TrainingActiveView` | 开 | 核心计数；暂停时停止处理或降低处理频率（实现权衡） |
| `SetCompleteView` 及之后 | 关 | 释放资源 |

### 4.3 UI 侧伪代码（Swift 风格，连接「引擎」）

下列名称仅为文档约定，工程可用 `ObservableObject` / `@Observable` 等实现。

```swift
enum TrainingPhase: Equatable {
    case idle
    case active
    case paused
    case completed
    case fault(String)
}

/// 由工程实现：封装 Core Motion、滤波、个体模板与双区间状态机（见 docs/01）
protocol RepetitionEngine: AnyObject {
    func startMonitoring(context: TrainingContext, onEvent: @escaping (EngineEvent) -> Void)
    func pauseMonitoring()
    func resumeMonitoring()
    func stopMonitoring()
}

enum EngineEvent {
    case repCompleted
    case targetReached
    case failure(String)
}

@MainActor
final class TrainingSessionController: ObservableObject {
    let context: TrainingContext

    @Published private(set) var currentReps: Int = 0
    @Published private(set) var phase: TrainingPhase = .idle

    private let engine: RepetitionEngine

    init(context: TrainingContext, engine: RepetitionEngine) {
        self.context = context
        self.engine = engine
    }

    var targetReps: Int { context.targetReps }
    var actionName: String { context.action.name }
    var currentSet: Int { context.currentSet }

    var accentColor: Color {
        switch phase {
        case .active: return Color("Brand.primary")
        case .paused: return Color("Semantic.warning")
        case .completed: return Color("Semantic.success")
        case .fault: return Color("Semantic.error")
        case .idle: return Color("Text.secondary")
        }
    }

    func startActiveCounting() {
        phase = .active
        engine.startMonitoring(context: context) { [weak self] event in
            switch event {
            case .repCompleted:
                self?.currentReps += 1
                playHaptic(.click)
            case .targetReached:
                playHaptic(.success)
                self?.phase = .completed
            case .failure(let reason):
                self?.phase = .fault(reason)
            }
        }
    }

    func pause() {
        phase = .paused
        engine.pauseMonitoring()
    }

    func resume() {
        phase = .active
        engine.resumeMonitoring()
    }

    func stop() {
        engine.stopMonitoring()
        phase = .idle
    }
}
```

圆点进度条（纯 UI）可在 `TrainingActiveView` 用 `currentReps` 与 `targetReps` 派生布尔数组：

```swift
func progressDots(current: Int, target: Int, maxDots: Int = 15) -> [Bool] {
    let n = min(target, maxDots)
    if target <= maxDots {
        return (0..<n).map { $0 < current }
    } else {
        let filled = Int(floor(Double(current) / Double(target) * Double(maxDots)))
        return (0..<maxDots).map { $0 < filled }
    }
}
```

### 5.1 `ActionListView`（入口）

**职责**：展示 5～8 个可选动作；进入历史。

**交互**：点选动作 → `RepsSettingView`；点「历史」→ `TrainingHistoryView`。

```swift
struct ActionListView: View {
```

### 5.2 `RepsSettingView`（目标次数）

**职责**：设定本组 `targetReps`（如 1…50）；确认后依模板是否存在进入 `CalibrationView` 或 `TrainingReadyView`。

**线框**：

```
┌────────────────────────────┐
│        杠铃卧推            │
│           12               │
│        目标次数            │
│   (−)    (✓)    (+)       │
└────────────────────────────┘
```

**交互**：`−` / `+` 调整；`✓` 短触感后导航。建议支持 **Digital Crown** 调次数（见第 7 节）。

**SwiftUI 骨架**：

```swift
struct RepsSettingView: View {
    let action: ActionRef
    @State private var targetReps: Double = 12

    var body: some View {
        VStack(spacing: Spacing.md) {
            Text(action.name)
                .font(.subheadline)
                .foregroundStyle(.secondary)
            Text("\(Int(targetReps))")
                .font(.system(size: 40, weight: .bold, design: .rounded))
            Text("目标次数")
                .font(.caption)
                .foregroundStyle(.secondary)

            HStack {
                Button { targetReps = max(1, targetReps - 1) } label: {
                    Image(systemName: "minus.circle.fill")
                }
                .buttonStyle(.borderless)

                Spacer()

                NavigationLink(
                    value: nextRoute()
                ) {
                    Image(systemName: "checkmark.circle.fill")
                        .font(.title)
                }
                .simultaneousGesture(TapGesture().onEnded { playHaptic(.click) })

                Spacer()

                Button { targetReps = min(50, targetReps + 1) } label: {
                    Image(systemName: "plus.circle.fill")
                }
                .buttonStyle(.borderless)
            }
            .padding(.horizontal)
        }
        .padding()
        .focusable()
        .digitalCrownRotation(
            $targetReps,
            from: 1, through: 50, by: 1,
            sensitivity: .medium,
            isContinuous: false,
            isHapticFeedbackEnabled: true
        )
    }

    private func nextRoute() -> Route {
        // 若 needsCalibration { return .calibration(...) } else { return .ready(...) }
        .ready(TrainingContext(action: action, targetReps: Int(targetReps), currentSet: 1))
    }
}
```

### 5.3 `CalibrationView`（个人模板）

**职责**：引导静止段与连续采样；成功写入模板后进入 `TrainingReadyView`；失败停留本页重试。

**线框**：

```
┌────────────────────────────┐
│ 请戴紧手表，单侧手腕         │
│ 保持起始姿势…               │
│ 请连续完成动作  3 / 8       │
│ [重试]            [完成]    │  // 正式版可仅保留必要按钮
└────────────────────────────┘
```

**SwiftUI 骨架要点**：文案用 `VStack` + `ProgressView`；`完成` 仅在引擎报告成功时可点；调试用的「跳过」勿带入正式构建。

```swift
struct CalibrationView: View {
    @StateObject private var vm: CalibrationViewModel

    var body: some View {
        ScrollView {
            VStack(alignment: .leading, spacing: Spacing.sm) {
                Text(vm.statusText)
                    .font(.body)
                if let p = vm.progress {
                    ProgressView(value: p)
                }
                Text(vm.sampleProgressText)
                    .font(.caption)
                    .foregroundStyle(.secondary)
            }
            .padding()
        }
        .navigationTitle("校准")
        .onAppear { vm.start() }
        .onDisappear { vm.cancel() }
    }
}
```

### 5.4 `TrainingReadyView`（准备 + 倒计时）

**职责**：再次提示佩戴/表冠朝向；用户点开始后 3 秒倒计时；结束后以 `replace` 语义进入 `TrainingActiveView`。

**SwiftUI 骨架**：

```swift
struct TrainingReadyView: View {
    let context: TrainingContext
    @State private var countdown: Int = 0
    @Environment(\.dismiss) private var dismiss

    var body: some View {
        Group {
            if countdown == 0 {
                VStack(spacing: Spacing.md) {
                    Text(context.action.name)
                        .font(.subheadline)
                        .foregroundStyle(.secondary)
                    Text("\(context.targetReps)")
                        .font(.system(size: 36, weight: .bold, design: .rounded))
                        .foregroundStyle(Color("Brand.primary"))
                    Text("次")
                        .font(.caption2)
                        .foregroundStyle(.secondary)
                    Button(action: startCountdown) {
                        Image(systemName: "play.circle.fill")
                            .font(.system(size: 44))
                    }
                    .buttonStyle(.plain)
                }
            } else {
                Text("\(countdown)")
                    .font(.system(size: 56, weight: .bold, design: .rounded))
                    .foregroundStyle(Color("Brand.primary"))
            }
        }
        .padding()
    }

    private func startCountdown() {
        playHaptic(.click)
        countdown = 3
        Task { @MainActor in
            while countdown > 0 {
                try? await Task.sleep(nanoseconds: 1_000_000_000)
                countdown -= 1
                if countdown > 0 { playHaptic(.click) }
            }
            playHaptic(.start)
            // 通过路由替换进入 TrainingActiveView
        }
    }
}
```

### 5.5 `TrainingActiveView`（训练中）

**职责**：展示当前次数、目标、进度点；暂停/继续/结束；与 `TrainingSessionController` 同步。

**线框**：同旧版逻辑（头部动作名 + 组、当前次数、目标、点阵、底部控制）。

**SwiftUI 骨架**：

```swift
struct TrainingActiveView: View {
    @StateObject private var session: TrainingSessionController
    @State private var isTraining = true
    @Environment(\.dismiss) private var dismiss

    init(context: TrainingContext, engine: RepetitionEngine) {
        _session = StateObject(wrappedValue: TrainingSessionController(context: context, engine: engine))
    }

    var body: some View {
        VStack(spacing: Spacing.sm) {
            HStack {
                Text(session.actionName)
                Text("第 \(session.currentSet) 组")
                    .foregroundStyle(.secondary)
            }
            .font(.subheadline)

            Text("\(session.currentReps)")
                .font(.system(size: 44, weight: .bold, design: .rounded))
                .foregroundStyle(session.accentColor)

            Text("\(session.targetReps)")
                .font(.title3)
                .foregroundStyle(.secondary)

            ProgressDotsView(
                filledMask: progressDots(current: session.currentReps, target: session.targetReps)
            )

            if isTraining {
                Button {
                    session.pause()
                    isTraining = false
                    playHaptic(.click)
                } label: {
                    Image(systemName: "pause.circle.fill")
                        .font(.system(size: 44))
                }
                .buttonStyle(.plain)
            } else {
                HStack {
                    Button {
                        session.resume()
                        isTraining = true
                        playHaptic(.click)
                    } label: {
                        Image(systemName: "play.circle.fill")
                    }
                    Button {
                        session.stop()
                        dismiss()
                    } label: {
                        Image(systemName: "stop.circle.fill")
                    }
                }
            }
        }
        .padding()
        .onAppear { session.startActiveCounting() }
        .onDisappear { session.stop() }
        .onChange(of: session.phase) { _, new in
            if new == .completed {
                // path.append(.complete(SetSummary(...))) 或绑定到上层协调器
            }
        }
    }
}
```

### 5.6 `SetCompleteView`（组完成）

**职责**：展示本组结果；继续下一组或结束并保存、回根栈。

**交互**：「继续」将 `currentSet + 1` 写入新的 `TrainingContext` 并回到 `TrainingActiveView`；「结束」持久化本会话数据后 **弹出到根**（`NavigationPath` 清空或协调器重置）。

**SwiftUI 骨架**：

```swift
struct SetCompleteView: View {
    let summary: SetSummary
    var onContinue: (TrainingContext) -> Void
    var onFinish: () -> Void

    var body: some View {
        VStack(spacing: Spacing.md) {
            Image(systemName: "checkmark.circle.fill")
                .font(.system(size: 40))
                .foregroundStyle(Color("Semantic.success"))
            Text(summary.actionName)
                .font(.subheadline)
            Text("第 \(summary.setIndex) 组")
                .font(.caption)
                .foregroundStyle(.secondary)

            Text("\(summary.actualReps)")
                .font(.system(size: 48, weight: .bold, design: .rounded))
                .foregroundStyle(Color("Semantic.success"))
            Text("\(summary.targetReps)")
                .font(.title3)
                .foregroundStyle(.secondary)

            HStack(spacing: Spacing.lg) {
                Button {
                    playHaptic(.click)
                    var ctx = summary.contextForNextSet()
                    onContinue(ctx)
                } label: {
                    VStack {
                        Image(systemName: "arrow.clockwise.circle.fill")
                        Text("继续")
                            .font(.caption2)
                    }
                }
                .buttonStyle(.borderless)

                Button {
                    playHaptic(.click)
                    onFinish()
                } label: {
                    VStack {
```

## 7. 交互反馈（触感、提示、表冠）

### 7.1 触感（WatchKit）

| 场景 | 建议 `WKHapticType` |
|------|---------------------|
| 按钮确认 / 计数 / 暂停恢复 | `.click` |
| 倒计时每秒 | `.click` |
| 训练开始 | `.start` |
| 达标 | `.success` |

```swift
import WatchKit

func playHaptic(_ type: WKHapticType) {
    WKInterfaceDevice.current().play(type)
}
```

### 7.2 提示与对话框

- **简短状态**：优先 `Text` + 自动消失逻辑，或使用 watchOS 合适的轻量反馈；避免照搬手机「Toast」组件名。
- **删除等破坏性操作**：使用 `confirmationDialog`（见历史页示例）。

### 7.3 Digital Crown（目标次数）

与 `RepsSettingView` 一致，使用 `digitalCrownRotation` 绑定 `1…50` 的 `Double` / `Int`，并在 `Stepper` 或自定义按钮间保持一致。

```swift
@State private var targetReps: Double = 12

// 在包含减号/加号与中央数字的容器上：
.focusable()
.digitalCrownRotation(
    $targetReps,
    from: 1, through: 50, by: 1,
    sensitivity: .medium,
    isContinuous: false,
    isHapticFeedbackEnabled: true
)
```
