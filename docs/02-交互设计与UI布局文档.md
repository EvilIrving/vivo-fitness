## 1. 设计规范

### 1.1 设计基准

```
原始设计宽度: 466px (vivo Watch 5)
Apple Watch 参考:
  - 41mm: 352 × 430 像素
  - 45mm: 396 × 484 像素
  - Ultra: 502 × 410 像素
```

```
主色 (Brand):    #405EFF  // 蓝色，用于主按钮、计数、强调

  gray-800:      #1F2937  // 主文字

```


## 2. 页面导航结构

### 2.1 页面路由

```
/pages/ActionList      ← 入口页，动作列表
    │
    ├── /pages/RepsSetting       ← 设置目标次数
    │       │
    │       └── /pages/TrainingReady    ← 训练准备（倒计时）
    │               │
    │               └── /pages/TrainingActive   ← 训练进行中
    │                       │
    │                       └── /pages/SetComplete  ← 组完成
    │                               │
    │                               ├── [继续] → /pages/TrainingActive
    │                               │
    │                               └── [结束] → /pages/ActionList
    │
    └── /pages/TrainingHistory   ← 历史记录
            │
            └── /pages/TrainingDetail   ← 训练详情
```

### 2.2 导航方式

| 操作 | 方式 | 说明 |
|-----|------|-----|
| push | 前进 | 保留返回栈，可返回 |
| replace | 替换 | 替换当前页，不保留 |
| back | 返回 | 返回上一页 |
| clear + replace | 清空返回 | 清空栈后跳转首页 |

### 3.2 次数设置页 (RepsSetting)

**页面职责：** 设置本组训练的目标次数

**布局结构：**

```
┌────────────────────────────┐
│                            │
│        杠铃卧推             │  ← 动作名称
│                            │
├────────────────────────────┤
│                            │
│           12               │  ← 目标次数（超大）
│        目标次数             │
│                            │
├────────────────────────────┤
│                            │
│   (−)     (✓)     (+)      │  ← 操作按钮
│                            │
└────────────────────────────┘
```

**交互规则：**
- 点击 `−` → 次数减 1（最小 1）
- 点击 `+` → 次数加 1（最大 50）
- 点击 `✓` → 进入训练准备页

**伪代码布局：**

```pseudocode
PAGE RepsSetting:
    LAYOUT: flex-column, full-height, justify-around, items-center
    BACKGROUND: white
    
    STATE:
        targetReps: Integer = 12 (默认值)
    
    SECTION ActionName:
        LAYOUT: flex-center
        CONTENT: Text(actionName, text-4xl, gray-500)
    
    SECTION Counter:
        LAYOUT: flex-column, items-center
        CONTENT:
            - Text(targetReps, text-5xl, bold, gray-800)
            - Text("目标次数", text-2xl, gray-500, margin-top-4)
    
    SECTION Controls:
        LAYOUT: flex-row, items-center, justify-center
        
        BUTTON Decrease:
            SIZE: 64×64, rounded-full
            STYLE: bg-gray-100
            ICON: minus.svg (32×32)
            ON_CLICK: 
                IF targetReps > 1 THEN targetReps -= 1
        
        BUTTON Confirm:
            SIZE: 80×80, rounded-full
            STYLE: bg-brand
            ICON: check.svg (40×40, white)
            ON_CLICK: 
                vibrate(SHORT)
                navigate("/TrainingReady", { actionCode, actionName, targetReps })
        
        BUTTON Increase:
            SIZE: 64×64, rounded-full
            STYLE: bg-gray-100
            ICON: plus.svg (32×32)
            ON_CLICK:
                IF targetReps < 50 THEN targetReps += 1
END PAGE
```

```
│                            │
├────────────────────────────┤
│                            │

│           次               │
│                            │
├────────────────────────────┤
│                            │
│          (▶)               │  ← 开始按钮
│                            │
└────────────────────────────┘
```

**布局结构 - 倒计时阶段：**

```
┌────────────────────────────┐
│                            │
│                            │
│                            │
│            3               │  ← 倒计时数字（超大）
│                            │
│                            │
│                            │
└────────────────────────────┘
```

**交互规则：**
- 点击开始 → 进入 3 秒倒计时
- 倒计时每秒短震动
- 倒计时结束长震动 → 跳转训练页

**伪代码布局：**

```pseudocode
PAGE TrainingReady:
    LAYOUT: flex-column, full-height, items-center, justify-between
    BACKGROUND: white
    PADDING: vertical-12
    
    STATE:
        countdown: Integer = 0
    
    SECTION PrepareView (visible when countdown == 0):
        LAYOUT: flex-column, full-height, items-center, justify-between
        
        // 顶部：动作名
        Text(actionName, text-3xl, gray-500)
        
        // 中间：目标次数
        COLUMN(items-center):
            Text(targetReps, text-5xl, bold, brand-color)
            Text("次", text-lg, gray-400, margin-top-4)
        
        // 底部：开始按钮
        BUTTON Start:
            SIZE: 80×80, rounded-full
            STYLE: bg-brand
            ICON: play.svg (40×40, white)
            ON_CLICK: startCountdown()
    
    SECTION CountdownView (visible when countdown > 0):
        LAYOUT: flex-column, full-height, items-center, justify-center
        CONTENT:
            Text(countdown, text-6xl, bold, brand-color)
    
    FUNCTION startCountdown():
        vibrate(SHORT)
        countdown = 3
        
        TIMER(every 1 second):
            countdown -= 1
            IF countdown > 0:
                vibrate(SHORT)
            ELSE:
                vibrate(LONG)
                DELAY(300ms)
                navigateReplace("/TrainingActive", { actionCode, actionName, targetReps })
END PAGE
```

### 3.4 训练进行页 (TrainingActive)

**页面职责：** 核心训练页面，实时显示计数和进度

**布局结构：**

```
┌────────────────────────────┐
│   杠铃卧推  第 1 组         │  ← 顶部信息
├────────────────────────────┤
│                            │
│           5                │  ← 当前计数（超大，带颜色）
│          ━━━               │
│           12               │  ← 目标次数
│                            │
│    ● ● ● ● ● ○ ○ ○ ○ ○     │  ← 圆点进度指示器
│    ○ ○ ○ ○ ○               │
│                            │
├────────────────────────────┤
│                            │
│          (⏸)               │  ← 训练中：暂停按钮
│                            │
│      (▶)    (⏹)            │  ← 暂停后：继续/结束
│                            │
└────────────────────────────┘
```

**颜色状态：**
- 训练中：蓝色 `#3B82F6`
- 暂停中：橙色 `#F59E0B`
- 完成：绿色 `#10B981`
- 错误：红色 `#EF4444`

**交互规则：**
- 检测到动作 → 计数+1，短震动，更新圆点
- 达到目标 → 长震动，绿色，跳转完成页
- 点击暂停 → 暂停传感器，显示继续/结束按钮
- 点击继续 → 恢复传感器
- 点击结束 → 返回上一页

**圆点进度算法：**

```pseudocode
FUNCTION updateProgressDots():
    MAX_DOTS = 15
    dotCount = MIN(targetReps, MAX_DOTS)
    
    IF targetReps <= MAX_DOTS:
        // 一一对应模式：每个圆点对应一次
        FOR i = 0 TO dotCount - 1:
            dots[i] = (i < currentCount)
    ELSE:
        // 比例模式：按比例填充
        filledDots = FLOOR(currentCount / targetReps × MAX_DOTS)
        FOR i = 0 TO MAX_DOTS - 1:
            dots[i] = (i < filledDots)
    END IF
END FUNCTION
```

**伪代码布局：**

```pseudocode
PAGE TrainingActive:
    LAYOUT: flex-column, full-height, items-center, justify-between
    BACKGROUND: white
    PADDING: vertical-12
    
    STATE:
        currentCount: Integer = 0
        currentSet: Integer = 1
        isTraining: Boolean = true
        countColor: String = "#3B82F6"
        progressDots: Array<Boolean>
    
    SECTION Header:
        LAYOUT: flex-row, items-center, justify-center
        CONTENT:
            - Text(actionName, text-2xl, gray-600)
            - Text("第 " + currentSet + " 组", text-2xl, gray-400, margin-left-2)
    
    SECTION Counter:
        LAYOUT: flex-column, items-center
        
        // 当前计数
        Text(currentCount, text-4xl, bold, color: countColor)
        
        // 分隔线
        Text("━━━", text-xl, gray-300, margin-top-1)
        
        // 目标次数
        Text(targetReps, text-3xl, gray-400, margin-top-1)
        
        // 圆点进度
        ROW(margin-top-8, flex-wrap, justify-center, gap-1.5):
            FOR EACH filled IN progressDots:
                DOT:
                    SIZE: 10×10, rounded-full
                    STYLE: 
                        IF filled: bg-brand
                        ELSE: border(1px, gray-300)
    
    SECTION TrainingControls (visible when isTraining):
        BUTTON Pause:
            SIZE: 80×80, rounded-full
            STYLE: bg-gray-300
            ICON: pause.svg (40×40)
            ON_CLICK: pauseTraining()
    
    SECTION PausedControls (visible when NOT isTraining):
        LAYOUT: flex-row, items-center, justify-center
        
        BUTTON Resume:
            SIZE: 80×80, rounded-full
            STYLE: bg-brand
            ICON: play.svg (40×40, white)
            ON_CLICK: resumeTraining()
        
        BUTTON Stop:
            SIZE: 80×80, rounded-full
            STYLE: bg-gray-300, margin-left-24
            ICON: stop.svg (40×40)
            ON_CLICK: stopTraining()
    
    LIFECYCLE onInit:
        initProgressDots()
        DELAY(SENSOR_START_DELAY):
            startSensorMonitoring()
    
    LIFECYCLE onDestroy:
        stopSensor()
END PAGE
```

## 4. 可复用组件

### 4.1 动作卡片 (ActionCard)

```pseudocode
COMPONENT ActionCard:
    PROPS:
        actionName: String
        category: String
        description: String
        icon: String
    
    RENDER:
        ROW(items-center, rounded-lg, bg-white, padding-4):
            COLUMN(flex-1):
                Text(actionName, text-2xl, bold, gray-800)
                Text(category, text-xl, gray-500, margin-top-1)
                Text(description, text-lg, gray-400, margin-top-1)
            Text("›", text-3xl, gray-300)
END COMPONENT
```

### 4.2 计数显示 (CounterDisplay)

```pseudocode
COMPONENT CounterDisplay:
    PROPS:
        count: Integer
        target: Integer
        color: String = "#3B82F6"
    
    RENDER:
        COLUMN(items-center):
            Text(count, text-9xl, bold, color: color)
            Text("/ " + target, text-3xl, gray-400, margin-top-2)
END COMPONENT
```

### 4.3 进度环 (ProgressRing)

```pseudocode
COMPONENT ProgressRing:
    PROPS:
        progress: Float (0-100)
    
    COMPUTED:
        percentage = ROUND(progress)
    
    RENDER:
        DIV(relative, items-center, justify-center):
            // 背景圆
            DIV(192×192, rounded-full, bg-gray-200, overflow-hidden):
                // 填充部分
                DIV(full-height, bg-brand, width: progress%)
            
            // 中心百分比
            DIV(absolute):
                Text(percentage + "%", text-5xl, bold, brand)
END COMPONENT
```

### 4.4 组次摘要 (SetSummary)

```pseudocode
COMPONENT SetSummary:
    PROPS:
        setNumber: Integer
        actualReps: Integer
        targetReps: Integer
        duration: Integer
    
    RENDER:
        COLUMN(rounded-lg, bg-gray-50, padding-4):
            Text("第 " + setNumber + " 组", text-2xl, gray-600)
            
            ROW(items-baseline, justify-between, margin-top-3):
                Text(actualReps, text-5xl, bold, brand)
                Text("/ " + targetReps + " 次", text-2xl, gray-400)
            
            IF duration:
                Text("用时: " + duration + "秒", text-lg, gray-400, margin-top-2)
END COMPONENT
```

### 4.5 训练记录项 (TrainingRecordItem)

```pseudocode
COMPONENT TrainingRecordItem:
    PROPS:
        actionName: String
        date: String
        totalReps: Integer
        setsCount: Integer
        duration: Integer
    
    RENDER:
        COLUMN(rounded-lg, bg-white, padding-4, shadow-sm):
            ROW(items-center, justify-between):
                COLUMN(flex-1):
                    Text(actionName, text-2xl, bold, gray-800)
                    Text(date, text-xl, gray-500, margin-top-1)
                
                COLUMN(items-end):
                    Text(totalReps, text-4xl, bold, brand)
                    Text("次", text-lg, gray-400, margin-top-1)
            
            ROW(items-center, justify-between, border-top, padding-top-3, margin-top-3):
                Text(setsCount + " 组", text-xl, gray-400)
                IF duration:
                    Text(duration + "秒", text-xl, gray-400)
END COMPONENT
```

## 6. Apple Watch 适配建议

### 6.1 SwiftUI 组件映射

| 原组件 | SwiftUI 替代 |
|-------|-------------|
| `div` + flexbox | `VStack`, `HStack`, `ZStack` |
| `list` + `list-item` | `List`, `ForEach` |
| `text` | `Text` |
| `image` | `Image` |
| 圆形按钮 | `Button` + `.clipShape(Circle())` |
| 滚动容器 | `ScrollView` |

### 6.2 导航替代

```swift
// NavigationStack (watchOS 9+)
NavigationStack {
    ActionListView()
        .navigationDestination(for: Action.self) { action in
            RepsSettingView(action: action)
        }
}

// 或 NavigationLink
NavigationLink(destination: RepsSettingView()) {
    ActionCardView()
}
```

### 6.3 震动替代

```swift
import WatchKit

func triggerHaptic(_ type: WKHapticType) {
    WKInterfaceDevice.current().play(type)
}

// 使用
triggerHaptic(.click)    // 短震
triggerHaptic(.success)  // 长震/成功
triggerHaptic(.start)    // 开始
```

### 6.4 Digital Crown 交互

可考虑使用 Digital Crown 调整目标次数：

```swift
@State private var targetReps: Double = 12

Stepper(value: $targetReps, in: 1...50) {
    Text("\(Int(targetReps))")
}
.focusable()
.digitalCrownRotation($targetReps, from: 1, through: 50, by: 1)
```
