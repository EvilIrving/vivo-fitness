## 1. 产品概述

### 1.1 产品定位

**健身计数助手** 是一款基于智能手表传感器的健身动作自动计数应用，帮助用户在力量训练过程中解放双手，专注于动作本身。

### 1.2 核心价值

| 价值点 | 描述 |
|-------|-----|
| 自动计数 | 用户选择动作并完成个人校准后，按闭环检测完成次数并计数 |
| 解放双手 | 训练中尽量减少操作，以震动反馈为主 |
| 个体模板 | 课前校准建立个人低位/高位（或展开/闭合）区间，再辅以组内自适应应对力竭 |
| 实时反馈 | 震动提示每次动作完成（可配置仅达标提示） |
| 数据沉淀 | 本地存储训练记录，追踪进步 |

### 1.3 目标平台与范围

| 平台 | 版本要求 | 说明 |
|-----|---------|-----|
| Apple Watch | watchOS 9+（以实现时为准） | **唯一目标客户端** |

**非目标（第一版明确不做或不做全）**

- 不做「全动作 AI 识别」：用户必须先选择动作。
- 不承诺覆盖所有力量训练动作：仅收录 **5～8 个** 经实测可稳定观测的动作；俯卧撑等手腕位移弱、个体差异大的动作默认不收录。
- 不支持任意佩戴位置（如脚踝）：与手腕不同的佩戴视为不同产品/配置，第一版 **仅支持单侧手腕、固定表冠朝向**（具体以交互说明为准）。
- 不依赖云端实时推理；数据以本地为主，可选后续通过 Watch Connectivity 同步 iPhone。

### 1.4 技术约束

```
1. 仅使用本地传感器，无需网络连接（MVP）
2. 数据本地存储，保护用户隐私
3. 低功耗：仅在训练会话中高频采样，结束即停
4. 算法轻量化：规则 + 状态机 + 个体模板为主，不默认上重型 ML
```

## 2. 用户画像与场景

### 2.1 目标用户

```
用户画像:
├── 健身爱好者
│   ├── 每周规律进行力量训练 2-5 次
│   ├── 有追踪训练数据的习惯
│   └── 希望提高训练效率
│
├── 健身初学者
│   ├── 刚开始接触力量训练
│   ├── 需要明确的目标引导
│   └── 希望培养健身习惯
│
└── 数据驱动型用户
    ├── 喜欢量化自己的进步
    ├── 关注训练频率和总量
    └── 重视长期数据积累
```

### 2.2 使用场景

#### 场景一：健身房力量训练

```
情境：用户在健身房进行杠铃卧推训练
流程：
1. 手腕佩戴智能手表
2. 打开应用，选择"杠铃卧推"
3. 设置目标次数（如 12 次/组）
4. 点击开始，3 秒倒计时准备
5. 开始训练，每完成一次手表震动提示
6. 达到目标后长震动提示
7. 选择继续下一组或结束保存
```

#### 场景二：居家健身

```
情境：用户在家进行哑铃弯举
流程：
1. 打开应用，选择"哑铃弯举"
2. 根据手边哑铃重量调整目标次数
3. 开始训练，专注动作质量
4. 通过震动感知完成情况
5. 完成后查看本次训练统计
```

#### 场景三：查看训练历史

```
情境：用户想了解近期训练情况
流程：
1. 进入历史记录页面
2. 查看总训练次数和总计数
3. 浏览最近训练记录
4. 点击某条记录查看详情
5. 可长按删除不需要的记录
```

## 5. 数据模型设计

### 5.1 动作定义

```
Action (动作)
├── actionCode: String       // 唯一编码 (ACT_001, ACT_002, ...)
├── actionName: String       // 显示名称 (杠铃卧推, 器械夹胸, ...)
├── description: String      // 动作描述
├── category: String         // 分类 (胸部, 手臂, 肩部, 腿部)
├── icon: String             // 图标路径
└── sensorFeature: String    // 传感器特征描述
```

### 5.2 预设动作列表（第一版）

动作库 **宜少而精**：首批 **5～8 个** 仅在真实手表数据上验证通过的动作；下列为示例占位，实际上线以准入测试为准。

| 编码 | 名称 | 分类 | 描述 |
|-----|------|-----|------|
| ACT_001 | 杠铃卧推 | 胸部 | 上下推举行程，手腕可观测主特征轴 |
| ACT_002 | 器械夹胸 | 胸部 | 水平面夹合，依赖前臂与手腕一致摆动 |
| ACT_003 | 哑铃弯举 | 手臂 | 弯举类，多依赖角速度/姿态变化 |

未通过「双区间稳定穿越」测试的动作 **不得** 对用户开放。

### 5.3 训练记录结构

```
TrainingRecord (训练记录)
├── recordId: String         // 唯一ID (rec_20240115_001)
├── actionCode: String       // 动作编码
├── actionName: String       // 动作名称
├── date: String             // 日期 (YYYY-MM-DD)
├── timestamp: Integer       // 创建时间戳
├── sets: Array<SetData>     // 组次数据
├── totalReps: Integer       // 总次数
└── duration: Integer        // 总时长（秒）

SetData (组次数据)
├── setNumber: Integer       // 组号 (1, 2, 3...)
├── targetReps: Integer      // 目标次数
├── actualReps: Integer      // 实际完成次数
├── startTime: Integer       // 开始时间戳
├── endTime: Integer         // 结束时间戳
└── setDuration: Integer     // 用时（秒）
```

### 5.4 用户统计

```
UserStats (用户统计)
├── totalWorkouts: Integer   // 总训练次数
├── totalReps: Integer       // 总计数
├── totalDuration: Integer   // 总时长（秒）
└── lastWorkoutDate: String  // 最后训练日期
```

### 6.2 次数设置页

#### 功能描述
设置本组训练的目标次数，提供加减按钮调整。

#### 功能点
| 功能 | 描述 | 优先级 |
|-----|------|-------|
| 显示动作名称 | 顶部显示当前选择的动作 | P0 |

- [ ] 点击确认按钮有震动反馈

### 6.3 个人动作校准页

#### 功能描述

在首次使用该动作、或用户主动「重新校准」时，采集一小段传感器数据，生成 **个人动作模板**（低位/高位区间、最小行程等）。详见 `docs/01-核心算法说明文档.md` 第 3 节。

#### 功能点

| 功能 | 描述 | 优先级 |
|-----|------|-------|
| 佩戴说明 | 提示单侧手腕、表带松紧、左右手与表冠朝向 | P0 |
| 静止段 | 起始约 2 秒静止采样 | P0 |
| 引导重复 | 连续完成 5～10 次（可配置） | P0 |
| 结束静止 | 约 2 秒静止 | P1 |
| 成功/失败 | 成功则进入训练准备；失败则提示调整佩戴或重试 | P0 |

#### 验收标准

- [ ] 校准失败时不进入正式计数，避免无模板裸跑
- [ ] 同一动作可保存模板；换握法/换手后应提示重新校准

#### 功能描述

#### 功能点
| 功能 | 描述 | 优先级 |
|-----|------|-------|
| 准备信息 | 显示动作名称和目标次数 | P0 |
| 开始按钮 | 点击开始进入倒计时 | P0 |

```
- 点击开始按钮触发短震动

```

#### 验收标准
- [ ] 显示正确的动作名称和目标次数
- [ ] 点击开始后显示倒计时数字
- [ ] 倒计时期间每秒有震动反馈
- [ ] 倒计时结束有长震动
- [ ] 自动跳转到训练进行页

### 6.5 训练进行页

#### 功能描述
核心训练页面，基于用户选定的动作类型与 **已生成的个人模板**，实时检测 **双区间闭环** 并完成计数。

**核心算法特点：**
- 不识别动作类型（用户已选择）
- 以 **区间闭环** 判定一次重复，而非固定节奏或窄时间窗
- **个体模板为主**，组内自适应为辅，应对力竭

#### 功能点
| 功能 | 描述 | 优先级 |
|-----|------|-------|
| 信息显示 | 显示动作名、组号 | P0 |
| 计数显示 | 显示当前计数和目标 | P0 |
| 进度指示 | 圆点进度展示完成情况 | P1 |
| 自动计数 | 闭环检测有效重复，自动计数 | P0 |
| 组内自适应 | 在模板基础上随本组数据微调，减少漏计 | P0 |
| 震动反馈 | 每次计数短震动 | P0 |
| 暂停功能 | 暂停传感器监测 | P0 |
| 继续功能 | 恢复传感器监测 | P0 |
| 手动结束 | 暂停后可手动结束 | P0 |
| 达标跳转 | 达到目标自动跳转完成页 | P0 |

#### 业务规则
```
- 训练中: 蓝色 (#3B82F6)
- 暂停中: 橙色 (#F59E0B)
- 已完成: 绿色 (#10B981)
- 传感器启动延迟: 1000ms
- 达标后跳转延迟: 1500ms
- 圆点最多 15 个，超出按比例填充
- 计数依赖已存储的个人模板；组内自适应参数以实现为准
```

#### 验收标准
- [ ] 启动后 1 秒开始监测传感器
- [ ] 识别到一次有效闭环时计数 +1 并震动
- [ ] 力竭、慢速、中途停顿在约定产品定义下仍尽可能计数（与算法文档一致）
- [ ] 计数变化时更新进度圆点
- [ ] 点击暂停按钮停止计数，按钮变为继续/结束
- [ ] 点击继续恢复计数
- [ ] 点击结束返回上一页
- [ ] 达到目标次数后长震动并跳转

### 6.6 组完成页

#### 功能描述
展示本组完成情况，选择继续训练或保存结束。

#### 功能点
| 功能 | 描述 | 优先级 |
|-----|------|-------|
| 完成标识 | 显示完成图标和动作信息 | P0 |
| 结果展示 | 显示实际完成/目标次数 | P0 |
| 继续下一组 | 进入下一组训练 | P0 |
| 结束保存 | 保存记录返回首页 | P0 |

#### 业务规则
```
- 继续下一组: currentSet + 1
- 结束训练: 保存记录 → 清除会话 → 返回首页
- 保存成功显示 Toast 提示
```

#### 验收标准
- [ ] 显示本组完成次数和目标次数

```swift
// 使用 HKWorkoutSession 获得更好的传感器访问
let configuration = HKWorkoutConfiguration()

let session = try HKWorkoutSession(
    healthStore: healthStore,
    configuration: configuration
)
session.startActivity(with: Date())
```

| 滤波 | Filtering | 去除噪声的数据处理 |
