## 1. 产品概述

### 1.1 产品定位

**健身计数助手** 是一款基于智能手表传感器的健身动作自动计数应用，帮助用户在力量训练过程中解放双手，专注于动作本身。

### 1.2 核心价值

| 价值点 | 描述 |
|-------|-----|
| 自动计数 | 利用加速度计和陀螺仪识别动作，自动计数 |
| 解放双手 | 无需手动操作，佩戴手表即可记录 |
| 实时反馈 | 震动提示每次动作完成，沉浸式训练 |
| 数据沉淀 | 本地存储训练记录，追踪进步 |

### 1.3 目标平台

| 平台 | 版本要求 | 状态 |
|-----|---------|-----|
| vivo Watch 5 (BlueOS) | - | 原版 |
| Apple Watch | watchOS 9+ | 迁移目标 |

### 1.4 技术约束

```
1. 仅使用本地传感器，无需网络连接
2. 数据本地存储，保护用户隐私
3. 低功耗设计，避免快速耗电
4. 算法轻量化，保证实时响应
```

## 2. 用户画像与场景

### 2.1 目标用户

```
用户画像:
├── 健身爱好者
│   ├── 每周规律进行力量训练 2-5 次
│   ├── 有追踪训练数据的习惯
│   └── 希望提高训练效率
│
├── 健身初学者
│   ├── 刚开始接触力量训练
│   ├── 需要明确的目标引导
│   └── 希望培养健身习惯
│
└── 数据驱动型用户
    ├── 喜欢量化自己的进步
    ├── 关注训练频率和总量
    └── 重视长期数据积累
```

### 2.2 使用场景

#### 场景一：健身房力量训练

```
情境：用户在健身房进行杠铃卧推训练
流程：
1. 手腕佩戴智能手表
2. 打开应用，选择"杠铃卧推"
3. 设置目标次数（如 12 次/组）
4. 点击开始，3 秒倒计时准备
5. 开始训练，每完成一次手表震动提示
6. 达到目标后长震动提示
7. 选择继续下一组或结束保存
```

#### 场景二：居家健身

```
情境：用户在家进行哑铃弯举
流程：
1. 打开应用，选择"哑铃弯举"
2. 根据手边哑铃重量调整目标次数
3. 开始训练，专注动作质量
4. 通过震动感知完成情况
5. 完成后查看本次训练统计
```

#### 场景三：查看训练历史

```
情境：用户想了解近期训练情况
流程：
1. 进入历史记录页面
2. 查看总训练次数和总计数
3. 浏览最近训练记录
4. 点击某条记录查看详情
5. 可长按删除不需要的记录
```

## 5. 数据模型设计

### 5.1 动作定义

```
Action (动作)
├── actionCode: String       // 唯一编码 (ACT_001, ACT_002, ...)
├── actionName: String       // 显示名称 (杠铃卧推, 器械夹胸, ...)
├── description: String      // 动作描述
├── category: String         // 分类 (胸部, 手臂, 肩部, 腿部)
├── icon: String             // 图标路径
└── sensorFeature: String    // 传感器特征描述
```

### 5.2 预设动作列表

| 编码 | 名称 | 分类 | 描述 |
|-----|------|-----|------|
| ACT_001 | 杠铃卧推 | 胸部 | 上下直线推举运动，手臂垂直地面方向运动 |
| ACT_002 | 器械夹胸 | 胸部 | 水平面内双臂向中线夹合运动 |
| ACT_003 | 哑铃弯举 | 手臂 | 前臂垂直面内旋转运动 |
| ACT_004 | 坐姿推肩 | 肩部 | 垂直向上推举运动 |
| ACT_005 | 腿举 | 腿部 | 下肢推蹬运动（手表随手臂自然摆动）|

### 5.3 训练记录结构

```
TrainingRecord (训练记录)
├── recordId: String         // 唯一ID (rec_20240115_001)
├── actionCode: String       // 动作编码
├── actionName: String       // 动作名称
├── date: String             // 日期 (YYYY-MM-DD)
├── timestamp: Integer       // 创建时间戳
├── sets: Array<SetData>     // 组次数据
├── totalReps: Integer       // 总次数
└── duration: Integer        // 总时长（秒）

SetData (组次数据)
├── setNumber: Integer       // 组号 (1, 2, 3...)
├── targetReps: Integer      // 目标次数
├── actualReps: Integer      // 实际完成次数
├── startTime: Integer       // 开始时间戳
├── endTime: Integer         // 结束时间戳
└── setDuration: Integer     // 用时（秒）
```

### 5.4 用户统计

```
UserStats (用户统计)
├── totalWorkouts: Integer   // 总训练次数
├── totalReps: Integer       // 总计数
├── totalDuration: Integer   // 总时长（秒）
└── lastWorkoutDate: String  // 最后训练日期
```

### 6.2 次数设置页

#### 功能描述
设置本组训练的目标次数，提供加减按钮调整。

#### 功能点
| 功能 | 描述 | 优先级 |
|-----|------|-------|
| 显示动作名称 | 顶部显示当前选择的动作 | P0 |
| 目标次数显示 | 大字体显示当前目标次数 | P0 |

```
- 目标次数范围: 1 ~ 50
```

- [ ] 默认显示目标次数为 12

- [ ] 点击加号，次数 +1，最大为 50
- [ ] 点击确认按钮有震动反馈

### 6.3 训练准备页

#### 功能描述
给用户准备时间，显示 3 秒倒计时后自动开始训练。

#### 功能点
| 功能 | 描述 | 优先级 |
|-----|------|-------|
| 准备信息 | 显示动作名称和目标次数 | P0 |
| 开始按钮 | 点击开始进入倒计时 | P0 |
| 3秒倒计时 | 显示 3、2、1 倒计时 | P0 |
| 倒计时震动 | 每秒短震动提示 | P0 |
| 自动跳转 | 倒计时结束后自动开始训练 | P0 |

```

```

#### 验收标准
- [ ] 显示正确的动作名称和目标次数
- [ ] 点击开始后显示倒计时数字
- [ ] 倒计时期间每秒有震动反馈
- [ ] 倒计时结束有长震动
- [ ] 自动跳转到训练进行页

## 7. Apple Watch 平台增强建议

### 7.1 watchOS 原生功能集成

#### 7.1.1 HealthKit 集成

```
建议接入 HealthKit:
├── 写入训练数据 (HKWorkout)
│   ├── workoutActivityType: .traditionalStrengthTraining
│   ├── duration: 训练时长
│   └── totalEnergyBurned: 估算消耗热量
│
├── 读取心率数据
│   └── 训练期间心率监测
│
└── 数据同步到健康 App
    └── 用户可在 iPhone 上查看
```

#### 7.1.2 Workout Session

```swift
// 使用 HKWorkoutSession 获得更好的传感器访问
let configuration = HKWorkoutConfiguration()
configuration.activityType = .traditionalStrengthTraining
configuration.locationType = .indoor

let session = try HKWorkoutSession(
    healthStore: healthStore,
    configuration: configuration
)
session.startActivity(with: Date())
```

```
建议开发表盘小组件:
├── 快速启动训练

```
