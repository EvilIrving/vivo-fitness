# 规格说明：位移检测增强

> 增强动作完成检测算法，支持力竭/匀速/离心控制场景

---

## Summary

为 `ActionRecognizer` 增加位移检测能力，使其能够识别匀速完成的动作，覆盖以下场景：
- 力竭阶段：用户只能以平缓速度完成动作
- 离心控制：高级训练者刻意慢速回程以增加肌肉张力
- 康复训练：需要缓慢、控制地完成动作

---

## Goals

1. **支持匀速动作检测**：即使没有明显加速度变化，也能检测动作完成
2. **支持双轴监测**：如面拉（Y轴水平+Z轴垂直）等复合动作
3. **保持向后兼容**：现有动作参数无需强制修改，新功能为可选增强
4. **不增加误检率**：通过时间窗口和峰值门限控制精度

## Non-goals

- 不追求精确位移测量（仅需检测"是否有足够位移"）
- 不改变现有 UI/UX 流程
- 不引入机器学习模型

---

## User Flows

### 场景1：力竭阶段完成动作

**操作**：用户在一组训练的后几次，以匀速缓慢地完成动作

**反馈**：
- 系统检测到位移变化，触发计数
- 震动反馈正常
- 计数器 +1

**回退**：如果位移检测也未触发，用户可手动调整目标次数

### 场景2：离心控制训练

**操作**：用户爆发式推起（去程），然后刻意慢速放下（回程）

**反馈**：
- 去程通过加速度检测
- 回程通过时间+稳定性检测
- 完整周期确认，计数 +1

### 场景3：双轴复合动作（面拉）

**操作**：面拉动作同时涉及水平拉动和垂直位移

**反馈**：
- 系统同时监测 Y轴（水平）和 Z轴（垂直）
- 任一轴位移达标即可辅助判定
- 计数正常

---

## Edge Cases

| 场景 | 处理方式 |
|-----|---------|
| 用户调整姿势（非训练动作） | 时间窗口过短，不计数 |
| 传感器抖动/噪声 | 加速度门限过滤 + 高通滤波 |
| 动作中途停止 | 超时重置，不计数 |
| 极慢动作（>3秒） | 超出时间窗口上限，不计数 |

---

## Acceptance Criteria

1. [ ] 匀速完成的动作能被正确识别（加速度峰值 < 正常值的 50%）
2. [ ] 现有爆发力动作识别不受影响（回归测试通过）
3. [ ] 位移检测功能可通过参数开关控制
4. [ ] TestModeView 能显示实时位移估计值
5. [ ] 核心算法文档已更新
